# 段取りマスター — MULTI_TASK

家事を同時進行でこなすマルチタスクゲーム。待ち時間を使い倒して、段取りよくハイスコアを狙おう。

## 遊び方

- **依頼が来たらタップで開始** — ベルが鳴った機械をタップ。早く始めるほど QUICK ボーナス。
- **待ち時間に次の作業** — 同時に動いている機械が多いほど MULTI 倍率アップ(最大 x3)。3つ・4つ同時進行でボーナス。
- **終わったらすぐ回収** — 金色に光っている間にタップで PERFECT。放置すると失敗。
- **皿洗いで隙間を埋める** — 連打で洗う。7枚たまるとあふれて失敗。

1ラウンド90秒。スコアはブラウザ(localStorage)に上位10件まで記録されます。
PC ではキーボード `1`〜`5` で操作、`Space` で一時停止。

| 機械 | 内容 |
|---|---|
| 洗濯機 | 12秒。時間がかかるので最初に |
| 炊飯器 | 4回タップで米を研いでから10秒 |
| 目玉焼き | 5秒。回収猶予が短く焦げやすい |
| やかん | 7秒。鳴ったら止める |
| 皿洗い | 3回こすって1枚 |

## 構成

ビルド不要の静的サイトです。絵文字は使わず、イラスト・アイコンはすべてインライン SVG、効果音は Web Audio で生成しています。

- `index.html` — 画面
- `style.css` — 見た目・アニメーション
- `game.js` — ゲームロジック
- `favicon.svg`

ローカルで遊ぶには `index.html` をブラウザで開くだけです。

## GitHub Pages で公開

リポジトリの **Settings → Pages → Build and deployment** で
Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存すると、
`https://<ユーザー名>.github.io/multi_task/` で公開されます。
